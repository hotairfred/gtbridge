# FlexRadio Network Tuning Guide

Notes from FlexRadio community forums on resolving audio stutter, CW latency, and general UDP performance issues — especially with multiple slices on the Flex 6700.

## Top Fixes

### 1. Disable Green Ethernet / Energy Efficient Ethernet (EEE)

The #1 cause of audio dropouts. Power-saving modes put switch ports to sleep during low activity, causing micro-dropouts when they wake up. Disable on both the Flex port and the PC port.

### 2. Hard-Code Flex Port to 100M Full Duplex

Gigabit auto-negotiation can cause timing issues, especially on boot — the switch initiates negotiation before the radio's ethernet interface is fully initialized, resulting in mismatched settings and intermittent packet loss.

The Flex only needs ~500 kbps per panadapter at 25 FPS — nowhere near gigabit capacity. Multiple users report 100 Mbps performs better than gigabit.

### 3. Disable Interrupt Moderation on PC NIC

In the PC's network adapter advanced properties:
- Set **Interrupt Moderation** (or Interrupt Moderation Rate) to **OFF**
- Disable **"Allow the computer to turn off this device to save power"** in Power Management tab
- **Maximize adapter buffers and descriptors** — set receive/transmit buffer values as high as possible

### 4. Reduce Panadapter / Waterfall Bandwidth

With multiple slices, waterfalls generate the majority of network traffic:
- Reduce panadapter frame rate
- Minimize or turn off waterfalls you're not actively watching
- Each panadapter at 25 FPS and 1500px width generates ~500 kbps
- Receive audio codec runs under 80 kbps regardless of slice count

### 5. QoS (Quality of Service)

If your router supports it, prioritize the FlexRadio's UDP traffic. Most important for remote (SmartLink) operation but can help locally too.

## Recommended Switches

| Switch | Type | Notes |
|--------|------|-------|
| Cisco SG200/SG300 | Managed | Tim W4TME's pick. Metal chassis, low RFI. |
| Cisco SG350 | Managed | Newer replacement for SG300. |
| Netgear GS108T | Managed | Solid with 3+ simultaneous SDR clients. |
| TP-Link TL-SG1024DE | Managed | Budget managed option, multiple users recommend. |
| Netgear GS-308 | Unmanaged | Works fine for simple setups. |

### General Switch Guidance

- **Metal chassis preferred** — better shielding from RFI generated by the radio
- **Business-class switches** (Cisco, Netgear ProSafe, TP-Link business) over consumer-grade
- **Managed switches recommended** — lets you see port errors, packet loss, and collisions when troubleshooting
- **Avoid "smart" or "easy smart" consumer switches** — sometimes have buggy firmware
- **Fiber optic isolation** is an advanced option (~$100) — immune to RF, ground loops, and surges

## Common Causes of Stutter/Latency

1. **Green Ethernet / EEE** — switch enters power-saving mode during low activity
2. **Gigabit auto-negotiation mismatch** — especially on boot
3. **Bufferbloat** — excessive latency from overfilled network buffers (check DSLReports bufferbloat grade)
4. **WiFi or repeaters in the path** — always use wired connections
5. **Interrupt moderation on PC NIC** — batches packets, adding latency
6. **Consumer switches with small packet buffers** — overflow under sustained UDP traffic
7. **RFI coupling into ethernet cables** — fix with Mix 31 ferrites or shielded (STP) cable
8. **Multiple devices competing for bandwidth** — configure QoS if needed
